# Final HTML Presentation

Open `index.html` directly in a modern browser. It is a self-contained,
read-only 10-minute presentation generated from the canonical `artifact.json`;
it does not require a local server, network access, or sibling assets.

The reading order follows the assignment:

1. problem and why;
2. background research and a surprising fact;
3. ideation and scope;
4. what failed;
5. future signal;
6. testing and case evidence;
7. recommendation; and
8. risks.

`BUILD_RECEIPT.json` records the final packaging result. Artifact validation,
packaging, payload equality, and structural checks passed. Enhanced Chromium
verification was unavailable after the cached headless shell entered fallback
and the installed Chrome timed out. The generated semantic fallback retains
all narrative, metric values, chart data tables, exact result tables, and
source inventory.

01 · The business problem

Messy files turn data entry into a judgment call

A contractor may send a spreadsheet, an API record, or a note. The same charger can be described differently—or have important information missing.

What arrives

  • Different column names and file formats
  • Power reported in different units
  • Missing or conflicting numbers

What an employee must decide

  • Which value can be trusted?
  • Where did that value come from?
  • Is the record ready, or must someone review it?

Our project focuses only on this first check. We did not use Con Edison internal data or claim measured labor savings.

02 · What we learned from research

Even national databases combine mismatched sources

What we found

The U.S. Department of Energy's charging-station directory combines daily network feeds, spreadsheet/CSV imports, and records maintained by people.

What this means: A useful system must show what it knows, what it does not know, and which original field supports each answer. A complete-looking row is not enough.

Sources: DOE Alternative Fuels Data Center; NREL developer documentation; Con Edison PowerReady; NYSDPS Case 18-E-0138.

07 · Our recommendation

Use it as an assistant—not as the decision-maker

The evidence supports a limited, fully human-reviewed pilot of Codex with safety rules. It does not support production deployment; a person must review every suggested record.

Rules for the trial

  • Use only approved test data and keep the original file
  • Show exactly where every suggested value came from
  • Do not let the tool update an official system
  • Stop the trial after any invented critical value or unsafe approval

Before considering wider use

  1. Add the 8-versus-6 conflict rule
  2. Improve source tracking in written notes
  3. Test a larger set labeled by independent reviewers

07 · 我们的最终建议

把它当作助手，而不是最终决策者

现有证据只支持一个有限、全程人工复核的 Codex 试点，不支持生产部署；每一份 AI 整理结果都必须由人检查。

试点必须遵守的规则

  • 只使用获批的测试数据，并保留原文件
  • 每个建议数值都必须显示来自原文件的哪里
  • 不允许工具更新任何正式系统
  • 出现一次关键数值编造或错误放行，就停止试点

考虑扩大使用之前

  1. 加入“8 还是 6”的冲突检查规则
  2. 改善文字材料中的来源定位
  3. 使用由独立人员标注的更大测试集
